pad(reference_image: Image, **kwargs) → Image

Pad the image on top of another image.

Uses the same notation as numpy.pad. The image is shifted aligning its top-left voxel with the reference image. The two images must have the same voxel spacing. The shifted image is cropped if it extends out of the reference image.

Parameters:

reference_image (Image) – Image used as reference for padding.

Returns:

New image with same shape and spacing of the reference.
